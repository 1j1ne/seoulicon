# SEOULICON — 한국 NPU와 미국 AI 반도체

“한국의 NPU는 무엇이고, 미국의 AI 반도체와 어떻게 다른가?”를 일반인에게 설명하는 한국어 인터랙티브 웹사이트입니다.
**자료 기준일: 2026-11-22** (`src/data/meta.ts`의 `DATA_AS_OF`)

## 사이트 주소

**https://1j1ne.github.io/seoulicon/** — `main` 브랜치에 push하면 GitHub Actions가 자동으로 빌드해 GitHub Pages에 배포합니다(`.github/workflows/deploy.yml`).

## 로컬 실행

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # 타입 검사 + 프로덕션 빌드(dist/)
```

기술 구성: React 18 + TypeScript + Vite, 3D는 Three.js / React Three Fiber / drei.
3D 코드(three.js 약 225KB gzip)는 3D 섹션이 화면에 가까워질 때만 지연 로딩됩니다. WebGL을 쓸 수 없으면 2D 도식과 버튼형 부품 목록으로 대체합니다.

## 정보 구조

| # | 섹션 | 핵심 인터랙션 |
|---|------|--------------|
| ① | AI가 대답하는 순간 | 질문 입력 → 기기·인터넷·데이터센터·서버·가속기로 이동하는 흐름 애니메이션(단계 버튼 포함), 회전·확대·초기화가 되는 칩 3D 개념 모형 |
| ② | 질문 처리 과정 | 질문 도착 → 토큰화(서버 CPU) → PCIe로 NPU 전달 → 프리필(HBM→SRAM→연산 슬라이스, KV 캐시 저장) → 디코드(단어 하나마다 가중치 재읽기, 후보 확률) → 스트리밍. 첫 화면 질문과 연동, 재생·단계 이동·속도 조절 |
| ③ | 3D로 확대해 보기 | 화면을 가득 채운 3D 장면을 스크롤하면 데이터센터 → 랙 → NXT RNGD 서버(레일로 빼냄) → RNGD 카드(꺼냄) → 패키지(방열판 들어 올림) → 칩 내부 개념도까지 계속 확대됨. 오른쪽(좁은 화면은 아래) 설명 패널, 부품 클릭 설명, 드래그 회전, 전체 화면 모드(휠·방향키·스와이프로 확대/축소) |
| ④ | 한국 vs 미국 | 간단히 보기(전력·메모리·대역폭·소프트웨어·용도 5줄 표) ↔ 자세히 보기 전환. 3개 비교 그룹 탭(PCIe 카드 / 대형 HBM / 클라우드 전용). 8개 항목별 “왜 중요한가”, 근거 없는 칸은 “직접 비교 불가” |
| ⑤ | 제작·판매 과정 | 회사와 무관한 일반 흐름도(개발 / 생산·납품 / 고객 도입 3개 레인, 10단계 노드, 병행·반복·매출 흐름 표시) + 단계별 설명 패널(하는 일·담당·기간·한국과 미국의 차이·지연 요인) + 근거 Q&A |
| ⑥ | 후발주자 사례 | CUDA 장벽과 비교: AMD EPYC·AWS Graviton·Android 사례(출처 있는 수치·막대), 한국 NPU에 주는 교훈과 한계, 전략 대응표, “이 사이트의 분석”으로 구분한 의견 |
| ⑦ | 마무리 | 확인된 경쟁력 / 제약 / 판단 불가 / 적합한 고객 |

## 비교 대상

- **한국**: 리벨리온 ATOM-Max(판매 중), Rebel100·RebelRack(2026년 공개, 초기 공급), 퓨리오사AI RNGD(2026-01 양산), KT Cloud·삼성SDS NPU 클라우드 서비스
- **미국 판매용**: NVIDIA L40S(PCIe 체급 비교용), H200(Rebel100이 지목한 비교 대상), B300, AMD MI355X(MI450은 계획)
- **미국 자체 사용·클라우드 전용**: Google TPU Ironwood(판매용 표와 따로 표시)

## 데이터 갱신 방법

화면 코드와 데이터를 나눠 두었습니다. 수치를 바꿀 때는 `src/data/`만 수정하면 됩니다.

| 파일 | 내용 |
|------|------|
| `sources.ts` | 모든 출처(제목·발행처·URL·날짜·유형: 공식/독립 검증/언론/2차 자료) |
| `meta.ts` | 자료 기준일, 주장 유형(확인된 사실/제조사 주장/계산 결과/설명용 가정/검증 필요) |
| `products.ts`, `compare.ts` | 제품 사양과 항목별 비교 칸 |
| `timeline.ts` | 10단계 공정 설명, Q&A |
| `explorer.ts`, `conclusion.ts` | 3D 부품 설명, 결론 |
| `challengers.ts` | 후발주자 성공 사례·전략표·분석 |
| `photos.ts` | 3D 탐색 부품별 실제 사진(Wikimedia Commons 자유 라이선스, 작성자·라이선스·원본 링크) |

각 수치에는 `claim`(주장 유형)과 `src`(출처 id 배열)를 달아 주세요. 없는 출처 id는 개발 모드 콘솔에 경고가 뜹니다.

## 자료상의 한계 (검증이 더 필요한 항목)

- **같은 조건의 성능 비교 없음**: 2026년 MLPerf에서 리벨리온·퓨리오사의 제출을 확인하지 못했습니다. 처리량·지연시간은 모두 “직접 비교 불가”로 두었습니다.
- **가격 비공개**: 한국·미국 판매용 가속기 모두 공식 가격이 없어 가격 섹션은 두지 않았습니다. KT Cloud·삼성SDS NPU 요금, Google Ironwood 요금(출처 상충)도 확인하지 못했습니다.
- **2차 자료에만 의존한 수치**: B300 메모리·전력, RebelRack 랙 구성, Rebel100 제조 공정(4nm/3nm 표기 상충)은 “검증 필요”로 표시했습니다.
- **보도가 엇갈리는 사례**: 리벨리온 상장 시점, Ironwood GA 날짜(공식 블로그 2025-11-06 사용).
- **확인 못 한 항목**: 한국 NPU 출하 대수와 시장점유율(추정하지 않음), 모든 기업의 개발 시작일.
- **3D 재현 범위**: 서버·카드·패키지는 퓨리오사AI RNGD의 공개 형상(4U·카드 8장·약 3 kW 공랭, 듀얼 슬롯 패시브 카드, 인터포저 위 칩 1개 + HBM3 2스택)을 재현했고, 외관 디자인·부품 위치·다이와 패키지 크기는 근사입니다. 데이터센터 홀과 칩 내부는 개념 모형입니다. 3D 좌표는 `src/three/world.ts`에 모여 있습니다.
- 출처 다수는 이번 웹 검색 결과 요약을 바탕으로 정리했습니다. 공개 전에 각 링크의 원문을 한 번 더 확인하길 권장합니다.

> 범위: 데이터센터용 AI 반도체에 집중합니다. 스마트폰·PC의 모바일 NPU는 다루지 않습니다.

> 3D 탐색의 부품 사진은 Wikimedia Commons의 자유 라이선스 사진을 원본 서버에서 불러오며, 대부분 같은 역할을 하는 다른 제품의 대표 사진입니다(캡션에 표시). RNGD 자체 사진은 저작권 때문에 싣지 않고 퓨리오사AI 공식 페이지로 연결했습니다.
